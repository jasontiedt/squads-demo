## Why

The catalog refresh in #58 silently broke 9 deployUnit tests on `main` because no workflow runs the vitest suites on pull requests — only `e2e.yml` (Playwright) gates merges. The hotfix is #63.

This workflow closes that gap: `pnpm -r test` (rules + worker + web vitest) runs on every PR that touches `apps/`, `packages/`, or pnpm lockfiles, and on pushes to `main`.

## Why not fold into e2e.yml?

Different runtime profile — vitest is sub-15s, Playwright is multi-minute. Keeping them split lets unit failures surface fast and avoids serializing the e2e queue behind unit-test churn.

## Toolchain match

Same `pnpm/action-setup@v4` + node 20 + frozen-lockfile as the existing `e2e.yml`, plus `cache: pnpm` for faster installs.

## Verified
