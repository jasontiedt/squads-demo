## MVP-6 S6 — Card-play UI for non-unit cards + Reaction window modal

Replaces Lobby's catch-all PlayAction fall-through with kind-aware routing, and surfaces the server-opened reaction window in a blocking modal.

### Changes
- **`apps/web/src/views/Lobby.tsx`** — card-click handler now switches on `card.kind`:
  - `action` → PlayAction (unchanged)
  - `tactic` → unit-picker → PlayTactic
  - `upgrade` → unit-picker (own units) → PlayUpgrade
  - `technology` → PlayTechnology (immediate, no target)
  - `event` → PlayEvent (immediate)
  - `reaction` → disabled in hand (auto-triggered via modal only)
- **`apps/web/src/components/ReactionWindowModal.tsx`** (new) — overlay rendered when `state.pendingReactionWindow` is set AND `eligibleSeat === localSeat`. Filters hand via `@eoe/rules` `eligibleReactions` helper. Play or Pass dispatches the matching action.
- **`apps/web/src/components/ActiveEventsRail.tsx`** (new) — horizontal rail showing each player's `activeEvents` (cap 3) with `ticksRemaining` counters. Opponent top, own bottom.
- **`apps/web/src/components/board/Board.tsx`** — attachment indicator badge on units with attached Upgrades.
